📂 Kode Website Itu dari Mana?

Ada 3 kemungkinan sumber kode website Anda. Pilih salah satu yang sesuai dengan situasi Anda:

Opsi 1: Anda Sudah Punya File Website di Komputer (Paling Umum)

Jika Anda sudah punya file website hasil buatan sendiri atau dari download template, misalnya:

  • index.html

  • style.css

  • script.js

  • dan folder lain seperti images/, assets/, dll.

Caranya:

  1. Buat repository baru di GitHub (saya sudah pandu di Tahap 1).

  2. Upload semua file itu ke repository GitHub.

  3. Nanti Vercel akan mengambilnya dari GitHub.

Opsi 2: Anda Belum Punya Kode Sama Sekali (Mau Buat dari Nol)

Jika Anda belum punya kode apa-apa, kita bisa buat website sederhana dulu sebagai percobaan.

Caranya:

  1. Di komputer Anda, buat folder baru, misal website-saya.

  2. Di dalam folder itu, buat file bernama index.html.

  3. Buka file itu dengan Notepad (atau VS Code), lalu copy-paste kode di bawah ini:

Opsi 3: Ambil Template Gratis dari Internet (Untuk Tampilan Lebih Keren)

Jika ingin website yang lebih bagus tanpa coding, Anda bisa download template HTML/CSS gratis dari:

Caranya:

  1. Pilih template yang Anda suka, klik download.

  2. Ekstrak file ZIP-nya di komputer Anda.

  3. Upload semua file dan folder hasil ekstrak ke GitHub.

  4. Vercel akan otomatis mendeteksinya.

Opsi 4: (Untuk yang Sudah Mahir) Buat Pakai Framework

Jika Anda sudah terbiasa dengan React, Next.js, Vue, dll:

  • Buat project baru di komputer (npx create-next-app my-app, dll).

  • Upload ke GitHub.

  • Vercel akan otomatis mendeteksi framework dan melakukan build.

📌 Rekomendasi untuk Pemula

Saya sarankan Anda pakai Opsi 2 dulu (kode sederhana) untuk latihan. Setelah berhasil, baru nanti ganti dengan template yang lebih keren.

📂 Sekarang Kita Upload ke GitHub

Ikuti langkah-langkah di bawah ini satu per satu:

Langkah 1: Simpan File di Komputer Anda

  1. File yang Anda kirimkan ke saya sudah berupa !DOCTYPE html.txt.

  2. Ganti nama file tersebut menjadi index.html (hapus !DOCTYPE html.txt, ganti jadi index.html).

    • Caranya: klik kanan file -> Rename -> ketik index.html -> Enter.

Langkah 2: Buat Repository Baru di GitHub

  1. Buka github.com dan login ke akun Anda.

  2. Klik tombol hijau "New" (di sebelah kiri atas, atau di pojok kanan atas ada tanda + lalu pilih New repository).

  3. Isi:

    • Repository name: ketik khasnanet (atau nama lain, misal billing-rtrw).

    • Description: (opsional) isi Sistem Billing RTRW Net.

    • Public/Private: pilih Public (biar gratis dan mudah diakses Vercel).

    • Jangan centang "Add a README file", "Add .gitignore", atau "Add a license".

  4. Klik tombol "Create repository" di bagian bawah.

Langkah 3: Upload File index.html ke Repository

Setelah repository dibuat, Anda akan dibawa ke halaman repository kosong.

  1. Klik tombol "Upload files" (atau di bagian "Quick setup" ada tulisan "upload an existing file").

  2. Tarik file index.html dari komputer Anda ke area yang bertuliskan "Drag files here to add them to your repository".

  3. Di bagian bawah, tulis pesan commit, misal: Upload file index.html.

  4. Pastikan pilihan "Commit directly to the main branch".

  5. Klik tombol hijau "Commit changes".

✅ Setelah selesai, file index.html sudah ada di repository GitHub Anda.

Langkah 4: Kirim Pesan ke Saya

Setelah Anda selesai mengupload file ke GitHub, kirim pesan ke saya:

"TAHAP 1 SELESAI"

Nanti saya lanjutkan ke Tahap 2: Deploy ke Vercel.

⚠️ Catatan Penting

Aplikasi ini menggunakan Google Apps Script sebagai backend. Untuk bisa berfungsi penuh, Anda juga perlu:

  1. Membuat Google Sheet sebagai database.

  2. Membuat Google Apps Script project dan menempelkan kode backend-nya.

Tapi jangan khawatir, itu nanti akan kita bahas setelah website berhasil di-deploy ke Vercel. Untuk sekarang, fokus dulu mengupload file HTML ke GitHub.

Silakan mulai dari Langkah 1. Jika ada yang bingung, tanyakan langsung ke saya.
